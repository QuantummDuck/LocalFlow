# Changelog

All notable changes to LocalFlow are documented here. The format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/) and the project uses [Semantic Versioning](https://semver.org/).

## [1.0.0] - 2026-11-20

First public release.

### Added
- Push-to-talk (fn), hands-free (double-tap fn or fn+Space) and Esc to cancel, with the Flow Bar overlay.
- On-device speech recognition with Parakeet Ultra and cleanup with a fine-tuned Qwen3 1.7B, protected by an output guard.
- Command Mode (fn+⌃), Transforms (Polish, Prompt Engineer and up to 8 custom), Auto Apply after dictation.
- Dictionary with automatic learning from your edits, Snippets, per-category Styles and Insights.
- Scratchpad (⌥S), paste/copy last transcript, Wispr Flow history import.
- Light and dark themes, onboarding, and first-launch model download.
- English and Portuguese.
